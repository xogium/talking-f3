Talking F3 Patcher

Makes a version of the Zoom F3 firmware that speaks its menus, popups, dialogs, file names and status out loud, through the headphones. Everything happens on this computer: nothing is uploaded, and no internet connection is needed.

You need the official Zoom F3 firmware version 2.20 (the file F3SYSTEM.BIN from Zoom's F3 download page) and a microSD card.

1.Choose Zoom's firmware file

Download the F3 firmware from zoomcorp.com, unzip it, and choose the F3SYSTEM.BIN inside.

2.Choose how it speaks

The defaults are what the project's own F3 uses. You can try any setting with "Listen to a sample".

Languages to include

The voice follows the language set on the F3. Languages left out fall back to English.

eSpeak voice variants. "michel" is the default.

Different speed for some languages

Leave a box empty to use the speed above.

The voice also follows the F3's headphone VOLUME buttons.

Higher quality sounds clearer but takes more room. The F3 has room for about 4 MB of voices.

3.Build the talking firmware

This takes about a minute. Keep this page open.

4.Install it on the F3

  1. Copy the new F3SYSTEM.BIN to the top level of the microSD card (not inside a folder). If the card already has an F3SYSTEM.BIN, replace it.
  2. Use fresh batteries or the power adapter: the update does not run on low battery.
  3. With the F3 switched off, insert the card, hold the PLAY/PAUSE button and switch the F3 on.
  4. The F3 offers to update. Choose Execute and confirm. Do not switch off or remove the card while it updates.
  5. When it is finished, switch the F3 off and on again. After a moment you hear the chime, and the F3 speaks as you use it.

To go back to the normal firmware: do the same steps with Zoom's original F3SYSTEM.BIN version 2.20. The patch never touches the F3's startup code, so this always works.

Talking F3 is an independent accessibility project, not made or supported by Zoom. It changes only the main firmware area, never the boot area, and checks every file before offering it. Voices: eSpeak NG (GPL-3.0); audio coding: Opus (BSD). Source code, technical notes and the F3 guide for blind users: github.com/xogium/talking-f3.
